AUD/USD MATRIX: FOCUSED SAVED-RECORD RECONCILIATION

This audit explains the opportunity/account R gap for M_D1.25_B1.0. It reads
existing records only. No candle downloads, account replays, strategy changes,
executor calls or order APIs. No OANDA token is read by this code.

1. Keep your downloaded matrix summary and research archives as backups.
2. Extract this ZIP. Upload its CONTENTS to the SAME AUD/USD matrix research
   service, keeping the existing files and mounted /data volume. This package
   adds a separate entrypoint; it does not replace matrix calculation modules.
   Its Procfile chooses the audit when the host uses Procfiles.
3. Keep the existing value of AUDUSD_MATRIX_OUTPUT_DIR. Normally:
       AUDUSD_MATRIX_OUTPUT_DIR=/data/p32_audusd_long_matrix
   Add:
       AUDUSD_RECON_OUTPUT_DIR=/data/p32_audusd_reconciliation
   Keep the old matrix directory. Do not point its variable to the new output.
4. Change the service's explicit START COMMAND to:
       python audusd_pullback_reconcile.py
5. Redeploy. Open /health and check:
       AUDUSD_PULLBACK_RECONCILIATION_V1_2026_10_23
6. Open /status to start the audit. It checks 14 SAVED accounts. The old
   224-account matrix is not regenerated. Send any ERROR status JSON here.
7. When status is COMPLETE and validation is PASS, download:
       /results-reconciliation.zip
   Upload that ZIP here. Reports are capped below 20 MB.

The source records already exist on /data; they were deliberately left out of
the earlier small summary. The audit needs those files on the SAME service.
Do not download or upload the large full matrix archive just for this step.

If the matrix output root is unusual, keep its current variable value.
Only if necessary, explicitly set AUDUSD_RECON_SOURCE_DIR to the completed
signature directory, not the parent:
 /data/p32_audusd_long_matrix/d3e4d41b44993b99fd57f15cc18c213d940475b0286098e053cb84877f5e2f29

The audit rejects changed inputs instead of silently rebuilding them. It uses
the matrix runner's existing file lock to avoid reading while it is running.
It needs 48 MiB free in the new report directory, leaves old caches alone,
and recomputes this small attribution safely after restart.

Optional console-only run:
       python audusd_pullback_reconcile.py --run

This diagnoses saved assumptions and accounting; it does not repair uncertain
prices or prove the candidate tradable. The previous matrix found no passing
plateau. Do not change the live executor or strategy probe for this audit.
